# E-RICA 가두모집 퀴즈 아케이드

갤럭시탭 S10 Ultra의 가로 화면을 기준으로 조정한 픽셀 테마 퀴즈입니다. 노트북·모바일도 지원합니다. HTML·CSS·JavaScript로 구성한 정적 사이트라 GitHub Pages로 배포할 수 있습니다.

## 먼저 보기

- **태블릿 배포:** [GitHub Pages 배포 안내](DEPLOY.md)
- **문제와 이미지 편집:** [폴더 사용법](questions/README.md) · [200문항 목록](questions/INDEX.md)
- **이전 노트북 UI:** [보관 안내](versions/README.md) · [원본 화면](versions/laptop-v1/index.html)

## 이 PC에서 실행

**`실행하기.cmd`를 더블클릭**하면 문제 폴더의 변경 내용을 반영하고 `http://localhost:4173`을 엽니다. 행사 중 터미널 창을 유지하세요. Node.js는 현재 PC에 설치되어 있습니다.

```sh
npm start
```

간단한 미리보기는 `index.html`을 직접 열어도 됩니다. 기록을 한곳에 모으려면 같은 브라우저에서 같은 주소를 계속 사용하세요. 파일 직접 열기, localhost, 127.0.0.1, GitHub Pages는 서로 다른 저장소를 사용합니다.

## 행사 흐름

1. 메인의 **반속테스트 / 일반 모드 / 기록 모드** 중 하나를 누릅니다.
2. 이름과 학과를 입력합니다.
3. 퀴즈 모드는 정사각형 게임 카드에서 종목을 선택합니다. 탭 가로 화면에서는 2행 4열입니다. 반속테스트는 바로 측정 안내 화면으로 이동합니다.
4. 일반 모드는 난이도 1~5에서 두 문제씩 중복 없이 뽑으며 시간제한이 없습니다. 기록 모드는 전체 25문제를 3분 안에 풀고, 시간이 끝나면 미응답 문항은 오답으로 처리합니다. 선택한 답은 다음 문제로 넘어갈 때 확정됩니다.
5. 맞힌 개수·틀린 개수·점수·정답과 해설을 확인합니다. 원문에 해설이 없는 문항은 정답 안내를 표시합니다. 틀린 문제는 해설이 펼쳐집니다.
6. 결과는 자동 저장됩니다. 오른쪽 아래 **메인으로 돌아가기**로 다음 참가자를 받습니다.

상단 음표 버튼은 효과음을 켜거나 끄고, 전체화면 버튼으로 화면을 크게 볼 수 있습니다.

## 반속테스트

- 이름과 학과를 입력하고 화면을 누르면 빨간색으로 시작합니다. 매 회차 2~10초 사이의 무작위 시점에 초록색으로 바뀌며, 그 순간 화면을 터치합니다. 마우스 클릭·스페이스·Enter도 지원합니다.
- `1/3`, `2/3`, `3/3`으로 진행 상황을 표시하며 회차 사이에는 직전 결과를 확인하고 화면을 눌러 다음 측정을 시작합니다.
- 빨간색에서 누르면 해당 시도는 제외하고 같은 회차를 다시 진행합니다. 나가기 창을 열거나 다른 탭·창으로 이동하면 측정을 중단하고 해당 회차를 다시 시작합니다.
- 3회의 개별 반응속도, 최고 기록(최솟값), 평균 기록, 이름(가림), 학과, 참여 일시를 저장합니다. 단위는 ms이며 소수점 한 자리로 표시합니다.
- **기록보기 → 반속테스트**에서 평균이 빠른 순으로 순위를 확인합니다. 같은 평균은 공동 순위입니다. 이름·학과 검색, 최신순 정렬, 반속 기록 CSV 다운로드를 지원합니다.
- 퀴즈와 별도 저장 키(`erica.reaction.records.v1`)를 사용합니다. 저장 실패 시 결과 화면에서 재시도하거나 개별 CSV로 보관할 수 있습니다.
- 측정에는 `performance.now()`와 화면 갱신 시점을 사용합니다. 실제 결과에는 기기의 화면·터치 지연도 포함됩니다.

## 이미지 문제

200문항을 **게임 / 난이도 / 문항 폴더**로 나누었습니다. 질문 이미지는 일반 텍스트 보기 문제에도 추가할 수 있습니다. 이미지 보기는 정사각형 4개이며, 탭 가로 화면에서는 한 줄에 4개, 세로에서는 2×2로 표시합니다. 이미지는 잘리지 않게 표시하고 질문 이미지는 크게 열어볼 수 있습니다. 결과 해설에서도 선택한 보기와 정답 이미지를 확인할 수 있습니다.

```text
questions/valorant/level-03/question-05/
  question.json
  question.png       # 선택: 질문 이미지
  option-1.png       # 이미지 보기 사용 시 네 장 모두
  option-2.png
  option-3.png
  option-4.png
  explanation.png    # 선택: 해설 이미지
```

이미지가 제공되지 않은 문항도 퀴즈 흐름에서 제외하거나 게임을 잠그지 않습니다. 롤 난이도 3의 비어 있는 문항은 빈 질문·빈 보기 상태로 표시되며 번호를 선택해 다음 문제로 진행할 수 있습니다. 이미지를 채울 때 `question.json`의 `status`를 `ready`로 바꾸면 완성된 이미지 문제로 표시됩니다. 자세한 예시는 [폴더 사용법](questions/README.md)에 있습니다.

TXT는 질문·보기·정답·해설의 원본으로 사용합니다. TXT를 고친 뒤 `실행하기.cmd` 또는 GitHub Pages 빌드를 실행하면 각 문항의 `question.json`으로 자동 동기화됩니다. `layout`, 이미지 파일명, 준비 상태 같은 화면 설정은 문항 폴더의 `question.json`에서 관리합니다.

## 기록 보관

- 같은 기기·브라우저의 `localStorage`에 가린 이름, 학과, 게임, 정답 수, 소요 시간, 참여 일시를 저장합니다. 원본 이름은 저장하지 않습니다.
- 예: `홍길동 → 홍*동`, `김수 → 김*`. 한 글자는 `*`로 표시합니다.
- 일반 모드 순위와 기록 모드 순위는 별도 탭에 저장·표시됩니다. 기존 5문제 기록은 일반 모드 기록으로 유지됩니다.
- 정답 수가 같은 참가자는 공동 순위이며 시간은 순위에 영향을 주지 않습니다. 소요 시간은 함께 표시됩니다.
- 기록보기에서 게임별 필터, 이름·학과 검색, 순위순·최신순 정렬을 사용할 수 있습니다.
- **전체 기록 CSV**는 필터와 관계없이 모든 기록을 내려받습니다. 저장 실패 시 개별 결과 CSV 보관과 재시도도 지원합니다.
- **GitHub Pages는 참가자 기록을 모으는 서버가 아닙니다.** 탭과 노트북의 기록은 자동으로 합쳐지지 않습니다. 브라우저 데이터를 삭제하면 기록도 삭제되므로 CSV로 보관하세요.

## 빌드와 검증

```sh
npm run sync:txt       # TXT 수정 내용 → 각 question.json
npm run build:data     # 문제 폴더 → quiz-data.js, 문제 목록
npm run build          # GitHub Pages용 dist 생성
npm test               # 문항·채점·이미지 준비 상태 검증
npm run test:browser    # 기존 PC/모바일 흐름 검증
npm run test:tablet     # 터치 화면·이미지 보기·배포 경로 검증
npm run test:reaction   # 반속 3회 측정·터치·저장·CSV·화면 크기 검증
```

일반 실행과 배포 빌드는 외부 패키지가 필요하지 않습니다. 브라우저 자동 검증은 Playwright와 Microsoft Edge를 사용하므로 다른 개발 PC에서는 `npm ci`가 필요합니다. GitHub Actions가 문제 데이터를 생성하고 검증한 뒤 `dist/`만 배포하도록 설정했습니다.

터치 입력·DPR을 적용한 **1480×924, 1280×800, 1184×740 CSS 뷰포트**, 세로 회전, 정사각형 이미지 보기, 이미지 로드 실패·재시도, 이미지 정답·해설, GitHub Pages 하위 경로를 검증했습니다. 실제 탭 하드웨어에서는 아직 테스트하지 않았습니다. 화면 캡처는 `test-results/tablet/`에 생성됩니다. 테스트용 이미지는 테스트 브라우저에서만 주입하며 실제 문항에 포함되지 않습니다.

## 파일 구조

- `index.html`, `styles.css`, `tablet.css`, `app.js`: 화면과 인터랙션
- `quiz-core.js`: 추출·채점·기록 저장
- `reaction-core.js`, `reaction-ui.js`, `reaction.css`: 반응속도 측정·기록·화면
- `questions/`: 문항별 JSON·이미지와 게임 정보
- `quiz-data.js`: 생성된 출제 데이터
- `scripts/sync-from-txt.cjs`, `scripts/build-data.cjs`, `scripts/build-site.cjs`: TXT 동기화·데이터·사이트 빌드
- `.github/workflows/pages.yml`: Pages 자동 배포
- `assets/`: 픽셀 일러스트·로컬 폰트
- `versions/laptop-v1/`: 이전 노트북 UI 보관
