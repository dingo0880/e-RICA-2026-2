# 문제와 이미지를 함께 관리하기

**[200문항 목록 열기](INDEX.md)**에서 질문을 찾고 해당 문항 폴더로 이동하세요.

```text
questions/
  valorant/                  ← 게임
    level-03/                ← 난이도 3
      question-05/           ← 그 난이도의 5번 문제
        question.json        ← 질문, 보기, 정답, 해설, 준비 상태
        question.png         ← 질문에 보여줄 이미지 (선택)
        option-1.png         ← 1번 이미지 보기
        option-2.png         ← 2번 이미지 보기
        option-3.png         ← 3번 이미지 보기
        option-4.png         ← 4번 이미지 보기
        explanation.png      ← 해설 이미지 (선택)
```

이미지는 아직 제공되지 않았기 때문에 현재 폴더에는 `question.json`만 있습니다. 임의의 게임 이미지를 만들어 넣지 않았습니다. 질문 이미지 없이 보기 4개만 넣어도 되고, 질문 이미지와 보기 4개를 함께 넣어도 됩니다. 일반 텍스트 문제에도 질문 이미지를 추가할 수 있습니다.

## 이미지 파일 넣기

위 이름으로 파일을 넣으면 다음 빌드 때 자동으로 찾습니다. `.png` 대신 소문자 확장자 `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`, `.svg`도 지원합니다. 같은 이름의 여러 확장자가 있으면 자동 선택하지 않고 어떤 파일을 쓸지 지정하도록 안내합니다.

원하는 파일명을 그대로 쓰려면 `question.json`의 `image` 또는 `optionImages`에 **같은 폴더 안의 파일명**을 적으세요. 예: `"image": "문제 그림.jpg"`. 대소문자까지 일치해야 합니다. 외부 URL이나 다른 폴더 경로는 사용하지 않습니다.

보기 이미지가 하나라도 있으면 **네 개 모두** 있어야 출제됩니다. 이미지가 잘리지 않도록 `contain` 방식으로 표시하며, 바깥 보기 카드는 정사각형입니다. 탭 가로 화면에서는 1행 4열, 세로에서는 2행 2열입니다. 보기 아래에 긴 설명을 넣으면 이미지 영역을 가릴 수 있으므로 짧은 이름을 쓰거나 빈 문자열로 두세요.

## 유형 2 · 정사각형 이미지 보기 4장

롤 난이도 3 스킬 문제처럼 네 장의 이미지 중 하나를 고르는 방식입니다. 해당 문항 폴더에 다음처럼 저장하세요.

```text
option-1.png
option-2.png
option-3.png
option-4.png
```

`question.json`은 `"layout": "image"`, `"requiresImage": false`로 설정합니다. `options`의 이름은 각 사진 바로 아래에 표시됩니다. 이름 없이 이미지만 보여주려는 문제만 빈 문자열 4개를 사용하세요. 파일명과 정답 번호는 서로 맞아야 합니다. 예를 들어 정답 이미지가 `option-3.png`라면 `"answer": 3`입니다. 이미지와 질문·정답 준비가 끝나면 `"status": "ready"`로 바꾸세요.

보기 이미지는 원본 파일을 수정하지 않고 화면에서 자동으로 정사각형 중앙 크롭합니다. 정사각형의 가로 폭을 꽉 채운 뒤 넘치는 위·아래 또는 좌·우만 잘라내므로 사진 비율은 일그러지지 않습니다. 중요한 대상은 사진 중앙에 오도록 준비하세요.

## 유형 3 · 질문 이미지 1장 + 텍스트 보기

포켓몬 벰크 문제처럼 이미지 한 장을 보고 이름을 고르는 방식입니다. 해당 문항 폴더에는 다음 파일 하나만 넣습니다.

```text
question.png
```

`question.json`은 `"layout": "text"`, `"requiresImage": true`로 설정합니다. `options`에는 화면에 표시할 이름 4개를 적고 `optionImages`는 빈 문자열 4개로 둡니다. 벰크 문항의 정확한 이미지 경로는 `questions/pokemon/level-05/question-04/question.png`입니다. 이미지가 준비되면 `"status": "ready"`로 바꾸세요.

## question.json 수정

예를 들어 난이도 3의 5번 발로란트 문항에 이미지 보기 4개를 넣는 설정입니다. 내용과 정답은 실제 준비한 이미지에 맞춰 수정하세요.

```json
{
  "id": "valorant-3-5",
  "status": "ready",
  "layout": "image",
  "question": "다음 중 레이즈의 궁극기 아이콘은?",
  "image": "",
  "imageAlt": "",
  "options": ["", "", "", ""],
  "optionImages": ["option-1.png", "option-2.png", "option-3.png", "option-4.png"],
  "answer": 2,
  "explanation": "2번은 레이즈의 궁극기 대미 장식 아이콘입니다.",
  "explanationImage": "",
  "requiresImage": true,
  "sourceQuestion": "원래 문제지의 질문을 남겨두는 참고용 메모"
}
```

- **`answer`는 1, 2, 3, 4 중 하나**입니다. 개발 코드의 0부터 시작하는 번호를 쓰지 않아도 됩니다.
- `layout`은 텍스트 보기 4개면 `"text"`, 정사각형 보기 이미지 4개면 `"image"`입니다. 이미지 파일을 아직 넣지 않아도 `image`로 지정한 문항은 4개의 빈 정사각형 자리로 표시됩니다.
- `options`에는 보기 문구 4개를 넣습니다. 이미지 보기라면 위 예시처럼 빈 문자열 4개도 가능하며 화면에는 `보기 1`~`보기 4`가 표시됩니다. 그림만 보고 맞히는 문제라면 여기에 정답을 알려주는 이름을 적지 마세요.
- `imageAlt`는 질문 이미지의 대체 설명입니다. 정답이 노출되지 않는 설명을 적으세요.
- `status: "pending"`은 준비 중, `status: "ready"`는 출제 요청입니다. 이미지 문제는 이미지를 다 넣고 질문·보기·정답을 확인한 뒤 `ready`로 바꾸세요.
- `ready`여도 필요한 파일, 질문, 정답 또는 보기 4개가 누락되면 자동으로 준비 중 처리합니다.
- `requiresImage: true`이면 질문 이미지가 필요한 문항입니다. 질문 그림을 보고 텍스트로 답하는 문제는 `layout: "text"`와 함께 사용하세요. `layout: "image"`에는 보기 이미지 4개가 모두 필요합니다.
- `sourceQuestion`은 원문 보관용입니다. 참가자에게 표시되지 않고 출제 데이터에도 포함되지 않습니다.
- 질문에 이미지 삽입 지시나 정답 이름이 섞이지 않도록, 원문 이미지 지시는 `sourceQuestion`에만 남겼습니다. 롤 난이도 3은 원문 질문·보기·정답이 모두 비어 있어 직접 채워야 합니다.
- 현재는 게임별 5단계 × 단계별 5문항 구조입니다. 폴더명과 `id`는 변경하지 마세요.

## 수정 내용 반영

로컬 PC: `실행하기.cmd`를 다시 실행하거나 아래 명령을 실행한 뒤 브라우저를 새로고침하세요.

```sh
npm run build:data
```

원본 TXT를 수정했다면 `실행하기.cmd`를 다시 열거나 `npm run sync:txt`를 실행하세요. TXT의 질문·보기·정답·해설을 각 `question.json`에 반영하고, 문항 유형과 이미지 파일 설정은 유지합니다. `layout: "image"` 문항의 빈 보기 문구도 이미지 정답이 노출되지 않도록 유지합니다. GitHub Pages 빌드에서도 이 동기화를 자동 실행합니다.

GitHub: 문제 폴더와 이미지를 커밋해서 올리면 준비한 Actions가 자동으로 문제 데이터를 생성하고 배포합니다. 로컬 빌드 없이도 동작합니다. `.github/workflows/pages.yml`이 저장소에 있어야 하고 Pages 소스를 GitHub Actions로 설정해야 합니다.

질문·보기·정답·해설은 원본 TXT에서 수정하고, `layout`, `status`, 이미지 파일명은 각 폴더의 `question.json`에서 수정합니다. `quiz-data.js`와 `INDEX.md`는 자동 생성 파일이므로 직접 편집하지 마세요.
