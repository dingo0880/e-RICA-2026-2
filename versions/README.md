# 노트북 UI 원본 보관

`laptop-v1`은 갤럭시탭 대응을 시작하기 전 화면·퀴즈 데이터·폰트·일러스트를 복사한 버전입니다. 화면 코드는 그대로 보관했으며, Windows에서 실행되도록 실행 파일의 깨진 한글 안내만 영문으로 교체했습니다.

- 빠른 확인: `laptop-v1/index.html`을 브라우저에서 열기
- 기존 방식 실행: `laptop-v1/실행하기.cmd` 더블클릭
- 두 버전 모두 로컬 서버 기본 포트가 4173이므로 먼저 실행 중인 서버를 종료한 뒤 원하는 버전을 켜주세요.
- 브라우저 기록은 파일 백업에 포함되지 않습니다. 기존 기록은 같은 브라우저의 같은 주소에 남으며 CSV로 별도 보관할 수 있습니다.
- 현재 루트 버전도 노트북에서 실행됩니다. 이 보관본은 **이전 UI 그대로**가 필요할 때 사용합니다.
- GitHub Pages의 배포 결과 `dist/`에는 이 보관 폴더가 포함되지 않습니다.
