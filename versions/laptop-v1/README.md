# E-RICA 가두모집 퀴즈 아케이드

픽셀 아케이드 테마의 동아리 부스용 퀴즈 웹페이지입니다. HTML·CSS·JavaScript로 만들었으며, 실행에 외부 패키지나 인터넷 연결이 필요하지 않습니다. 원본 TXT 8개는 그대로 보관했습니다.

## 실행

**Windows: `실행하기.cmd`를 더블클릭하세요.** 브라우저가 열리고 `http://localhost:4173`에서 실행됩니다. 행사 중에는 함께 열린 터미널 창을 유지하세요. 종료할 때는 창을 닫거나 `Ctrl+C`를 누르세요. Node.js가 설치되어 있어야 합니다(현재 PC에는 설치되어 있습니다).

터미널에서는 다음과 같이 실행할 수도 있습니다.

```sh
npm start
```

간단한 미리보기는 `index.html`을 브라우저에서 직접 열어도 됩니다. **행사 기록을 한곳에 모으려면 같은 브라우저에서 `실행하기.cmd`로 여는 `http://localhost:4173` 주소를 계속 사용하세요.** 파일 직접 열기, localhost, 127.0.0.1, 다른 브라우저는 서로 다른 저장소를 사용합니다.

## 참여 흐름

1. 메인의 **퀴즈풀기** 또는 메인 일러스트 영역을 누릅니다.
2. 이름과 학과를 입력합니다.
3. 2행 4열의 게임 카드에서 종목을 고릅니다. 모바일에서는 2열로 표시됩니다.
4. 난이도 1~5에서 준비된 문제 중 한 문제씩 무작위로 뽑아 총 5문제를 풉니다. 답은 다음 문제로 넘어갈 때 확정됩니다. 시간제한은 없습니다.
5. 맞힌 개수·틀린 개수·점수와 정답을 확인합니다. 원문에 해설이 있는 문항은 그 해설을 표시하며, 별도 해설이 없는 문항은 정답 안내를 표시합니다. 틀린 문제의 해설은 자동으로 펼쳐집니다.
6. 결과는 즉시 자동 저장됩니다. 오른쪽 아래 **메인으로 돌아가기**를 눌러 다음 참가자를 받습니다.

상단의 음표 버튼은 효과음을 켜거나 끄고, 전체화면 버튼 또는 브라우저의 `F11` 키로 부스 화면을 크게 볼 수 있습니다.

## 기록 보관

- 브라우저 `localStorage`에 **가린 이름, 학과, 게임, 맞힌 개수, 소요 시간, 참여 일시**를 보관합니다. 원본 이름은 저장하지 않습니다.
- `홍길동 → 홍*동`, `김수 → 김*`, 한 글자 이름은 `*`로 처리합니다.
- 정답 수가 높은 순서로 순위를 정하며, 같은 정답 수는 공동 순위입니다. 소요 시간은 순위에 영향을 주지 않습니다.
- **기록보기**에서 게임 필터, 이름·학과 검색, 최신순 정렬을 사용할 수 있습니다.
- **전체 기록 CSV**로 엑셀에서 열 수 있는 파일을 내려받을 수 있습니다. 현재 필터와 관계없이 모든 기록을 내보냅니다.
- 저장소가 차단되거나 용량이 부족하면 저장 실패 안내와 재시도·개별 결과 CSV 보관 버튼이 표시됩니다.
- 서버가 참가자 기록을 보관하거나 여러 기기의 기록을 동기화하는 구조는 아닙니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 행사 기록은 CSV로 별도 보관하세요.

## 이미지 문제: 준비 중

요청에 따라 이미지가 없는 문항을 임의의 문제로 대체하지 않고 **준비 중**으로 분류했습니다. 전체 200문항 중 11문항이며, 출제 대상에서 제외합니다.

| 게임 | 이미지가 필요한 문항 | 현재 상태 |
| --- | --- | --- |
| 리그 오브 레전드 | 난이도 3의 1~5번: 질문·보기·정답·스킬 이미지가 필요 | 게임 전체 준비 중 |
| 발로란트 | 난이도 3의 5번, 난이도 5의 2번 | 나머지 문항으로 5단계 진행 |
| 오버워치 | 난이도 4의 2번 | 나머지 문항으로 5단계 진행 |
| 배틀그라운드 | 난이도 3의 1번, 난이도 5의 4번 | 나머지 문항으로 5단계 진행 |
| 포켓몬스터 | 난이도 5의 4번 | 나머지 문항으로 5단계 진행 |
| 전략적 팀 전투, 마인크래프트, LCK | 없음 | 전체 문항 사용 |

롤은 난이도 3의 모든 문제가 비어 있어, 총 5문제라는 규칙을 지키기 위해 카드에서 시작을 막아두었습니다. 이미지 문항이 준비되면 이미지 표시 기능과 해당 데이터를 추가하면 됩니다. 현재 버전은 이미지 파일만 폴더에 넣는 것으로 자동 연결되지는 않습니다.

문제와 정답은 제공된 TXT를 기준으로 반영했습니다. 패치·시즌에 따라 바뀌는 게임 정보의 사실관계를 별도로 수정하지 않았습니다.

## 문제 수정 및 검증

일반 텍스트 문항은 원본 TXT의 형식을 유지해서 수정하고 다음 명령으로 반영합니다.

```sh
npm run build:data
```

게임마다 난이도 5개, 난이도마다 원본 문항 5개가 있는지 검사하며 `quiz-data.js`를 생성합니다. 원본의 굵은 표시로 정답이 노출되지 않도록 질문과 보기에서 Markdown 표시를 제거합니다.

```sh
npm test
npm run test:browser
```

브라우저 검증은 개발 의존성인 Playwright와 설치된 Microsoft Edge를 사용합니다. 다른 PC에서 검증하려면 `npm ci`가 필요합니다. 일반 행사 실행에는 `npm ci`가 필요하지 않습니다.

검증 범위: 200문항 파싱, 이미지 문항 제외, 난이도별 무작위 추출, 0~5점 채점, 이름 가림, 중복 저장 방지, 공동 순위, CSV 처리, 7개 게임 실제 브라우저 완주, 새로고침 후 저장 유지, 저장 실패 처리, 모바일 가로 넘침. 스크린샷은 `test-results/`에 생성됩니다. 검증용 참가자 기록은 독립된 임시 브라우저에만 저장되므로 실제 행사 기록에 섞이지 않습니다.

## 주요 파일

- `index.html`, `styles.css`, `app.js`: 화면과 인터랙션
- `quiz-core.js`: 추출·채점·기록 관리
- `quiz-data.js`: TXT에서 생성한 문제 데이터
- `scripts/build-data.cjs`: 문제지 변환
- `assets/arcade.svg`: 직접 제작한 픽셀 아케이드 일러스트
- `assets/DungGeunMo.woff`: 인터넷 없이 사용하는 한글 픽셀 폰트
- `server.cjs`, `실행하기.cmd`: 로컬 실행

폰트와 디자인 자산 출처는 [ASSETS.md](ASSETS.md)에 정리했습니다.
